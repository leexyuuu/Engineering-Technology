# mock-exam 压力测试指南

## 一、这套测试能告诉你什么？

模拟 500 个学生**同时**进行一场完整考试（登录 → 答题 → 交卷），验证系统在高负载下是否正常工作。

测试完成后你会得到：
- 每秒能处理多少个请求（RPS）
- 每个操作的响应时间（越快越好）
- 失败率（必须为 0%）

---

## 二、安装（一行命令）

```bash
pip install locust
```

---

## 三、操作步骤

### 第 1 步：确保服务已启动

```bash
cd fapi
uvicorn app:app --host 0.0.0.0 --port 8000 --workers 4
```

### 第 2 步：准备测试数据

```bash
cd fapi/loadtest
python setup_test_data.py --host http://127.0.0.1:8000 --students 500
```

脚本会自动：创建 1 场考试 + 6 道题目 + 500 个测试学生。

运行结束后会显示考试 ID，把它填入 `locustfile.py` 第 18 行：
```python
TEST_EXAM_ID = 这里填考试ID
```

### 第 3 步：启动压测

```bash
cd fapi/loadtest
locust -f locustfile.py
```

### 第 4 步：浏览器打开控制台

打开 http://localhost:8089 ，填写：

| 参数 | 值 | 说明 |
|------|-----|------|
| Number of users | 500 | 模拟 500 个学生 |
| Ramp up | 50 | 每秒增加 50 个用户 |
| Host | http://127.0.0.1:8000 | 你的 API 地址 |

点击 **Start** 开始。

---

## 四、如何判断测试结果？

### 看什么指标？

Locust 界面上有一个表格和实时图表，重点看这几列：

| 指标 | 含义 | 通过标准 |
|------|------|----------|
| **Requests** | 总请求数 | 越大越好 |
| **Fails** | 失败数 | **必须为 0** |
| **Median (ms)** | 50%请求的响应时间 | < 500ms |
| **95%ile (ms)** | 95%请求的响应时间 | < 2000ms |
| **99%ile (ms)** | 99%请求的响应时间 | < 5000ms |
| **RPS** | 每秒处理请求数 | > 100 |

### 通过标准（一句话总结）

> **500 个用户跑完全流程，失败率 = 0%，95% 响应时间 < 2 秒，就算通过。**

### 各步骤的合理响应时间

| 步骤 | 期望 Median | 期望 95%ile |
|------|------------|-------------|
| 1-登录 | < 200ms | < 1000ms |
| 3-开始考试 | < 200ms | < 1000ms |
| 4-加载题目列表 | < 100ms | < 500ms |
| 5-保存答案 | < 200ms | < 1000ms |
| 6-交卷 | < 200ms | < 1000ms |

## 五、测试不通过怎么办？

### 情况 1：大量请求失败（Fails > 0）

**可能原因**：数据库连接耗尽

**解决**：检查 database.py 的连接池配置
```python
engine = create_engine(
    DATABASE_URL,
    pool_size=30,
    max_overflow=20,
)
```

### 情况 2：响应时间很长（95%ile > 5s）

**可能原因**：Worker 数量不够

**解决**：增加 uvicorn workers
```bash
uvicorn app:app --workers 8
```

### 情况 3：响应时间随用户数增加线性增长

**可能原因**：还在用 SQLite

**解决**：确认已切换到 MySQL，SQLite 的写锁会导致排队

### 情况 4：服务器直接挂了

**可能原因**：内存不足

**解决**：检查服务器配置，至少需要 4G 内存

## 六、建议的测试顺序

先跑小的，确认没问题再加量：

1. **50 人** — 先确认测试脚本能跑通
2. **200 人** — 验证基本并发能力
3. **500 人** — 目标验证
4. **800 人** — 压力上限摸底（可选）

每次测试间隔，重启一下服务端清理状态。

## 七、不用命令行？Locust 也可以直接跑

如果你不想用命令行，也可以用 headless 模式直接出报告：

```bash
locust -f locustfile.py \
  --headless \
  --users 500 \
  --spawn-rate 50 \
  --host http://127.0.0.1:8000 \
  --run-time 5m \
  --csv=report
```

跑完后会在当前目录生成 `report_stats.csv`，用 Excel 打开就能看。
