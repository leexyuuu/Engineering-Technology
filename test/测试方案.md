# 量化测试方案

- 项目：知行职业学院 · 排课选课与教务协作智能体（MVP）
- 版本：v0.4.0 ｜ 文档版本：v1.0 ｜ 编制日期：2026-11-06
- 依据：`docs/01_需求清单.md`、`docs/02_上线检查清单.md`、`eval/eval_cases.json`
- 配套：五份可视化测试过程文档（`test/正常场景测试.docx` 等）

## 1. 测试目标与质量门禁

本方案用**可计数、可复现**的断言验证 MVP 的四条底线：

| 编号 | 质量目标 | 量化门禁（P0，一票否决） |
| --- | --- | --- |
| G1 | 制度问答准确、可溯源、不编造 | 制度类用例通过率 = **100%**（7/7）；引用覆盖率 = **100%**；零命中编造 = **0 例** |
| G2 | 工具调用与 Agent 轨迹正确 | 工具类用例通过率 = **100%**（10/10）；单次决策轮次 **≤5** |
| G3 | 选课写入必须人工在环 | 未授权建单拦截率 = **100%**；状态机非法迁移拒绝率 = **100%**（40901） |
| G4 | 权限与故障边界不可突破 | 越权拒绝率 = **100%**；故障场景结构化错误返回率 = **100%**（无 500 裸栈） |
| G5 | 整体回归不倒退 | 自动化断言通过率 = **100%**；并发错误率 **<0.5%**；限流第 21 次必为 429+42901 |

任一 P0 指标不达标 → 不上线（与 `docs/02_上线检查清单.md` 第 7 节门禁一致）。

## 3. 测试策略：五类场景

| 场景 | 设计问题 | 主要方法 | 量化关注点 |
| --- | --- | --- | --- |
| 正常 | 该做的事是否都做对 | 端到端评测 + 回归脚本 + 全流程走查 | 通过率、引用率、工具序列一致性 |
| 边界 | 临界输入是否稳定 | 长度/数量/状态临界值探测 | 临界值通过/拒绝是否精确 |
| 对抗 | 恶意或诱导输入是否被挡 | 陷阱题、违规意图、提示注入 | 拒绝率、零写入 |
| 权限 | 越权是否一律拒绝 | 三角色矩阵 + 横向越权 + 伪造凭证 | 拒绝率、错误码一致性 |
| 故障 | 依赖失效时是否受控 | 坏端点、零命中、不存在资源、畸形请求、并发 | 结构化错误率、兜底率、0 裸 500 |

用例来源：`eval/eval_cases.json`（30 条）+ `scripts/stage3_test.py`（23 项）+ `scripts/stage3b_test.py`（20 项）
+ `scripts/stage4_test.py`（27 项）+ 五类专项探针（18 项）。**合计 118 项自动化断言**。

## 6. 执行流程

```text
① 准备：创建隔离 DB/索引目录 → 启动 mock 实例（8010）
        ↓
② 主套件（顺序执行，间隔 65 秒，避免 20 次/分钟限流互相干扰）

        ↓
③ 专项探针（18）：边界 → 权限 → 对抗 → 限流（最后执行，独占限流窗口）
        ↓
④ 判定：逐项 PASS/FAIL → 汇总通过率 → 对照第 1 节门禁

⑤ 留档：控制台输出 + 过程文档 + 截图/图表
```

### 9.2 已知限制

1. mock 数据无法构造“学分 >28”“先修 59 分”两个临界分支，需真实学籍数据接入后补测（规则代码已覆盖）。
2. “课程重名歧义”分支需构造重名课程数据，当前 mock 课程库无重名项。
3. 限流为进程内实现，多实例不适用；切换 Redis 后需重跑 P13/P14。
4. 供应商故障（FB-1）与并发（CL-4）本次未重复注入，采用 `docs/03_上线演练报告.md` 的实证结论。

### 9.3 供应商差异（重要）

本次量化基线使用 `mock` 供应商，原因是脚本对**工具序列**和**固定话术**做精确断言。
在真实供应商（如 Qwen）下复跑同一套脚本，观察到：

- 制度类回答会先调用 `search_selection_rules`（mock 下为零工具直答）；
- 同一问题可能重复检索（如连续 3 次 `search_selection_rules`），触发精确序列断言失败；
- 个别话术措辞变化（如“未满足先修课要求”vs“不符合先修”），导致关键词断言失败。

这些**不是功能缺陷**，而是断言口径问题。按 `eval/README.md` 约定：制度类只约束“禁用工具”，
工具/多轮类在真实供应商下应改用子集校验。**生产验收须在真实供应商下按兼容口径重跑并留存报告。**

## 10. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 限流干扰连续用例 | 误判为功能失败 | 套件间隔 65 秒；限流用例最后执行 |
| SQLite 写并发 | 偶发 locked | 单实例串行；高并发切 PostgreSQL |
| 真实供应商话术漂移 | 断言误报 | 采用子集断言；关键结论用结构化字段断言 |
| mock 数据覆盖不足 | 边界分支未测 | 真实学籍导入后补测临界值 |
| 操作污染共享库 | 结果不可复现 | 使用独立 DB/索引目录（本方案已隔离） |
